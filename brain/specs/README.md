# Frozen

This tree is frozen as of 2026-10-15. Do not edit it, cite its clause ids in new
work, or run spec-cleanup sittings on it.

without. They are read only at a capability's harvest step, with Alberto:
once the capability is rebuilt and its evals are written, any clause worth
keeping becomes an eval, and the capability's spec files are deleted
(CONTRIBUTING.md § Building a capability).
