# fleet

The repository of tinyfleet, which runs AI coding agents on your own projects.

tinyfleet is being built again from scratch, one capability at a time. What it
must do, and how it is built, are written down rather than read out of the
code:

- `brain/prd/` holds the PRDs: `seed.md` for the product, one file per
  capability.
- `brain/architecture/core.md` is the architecture doc: how tinyfleet is
  shaped, in what language, and the rules its code keeps.
- `CONTRIBUTING.md` is the method; `AGENTS.md` is its short form for agents.

The implementation from before 2026-10-15 is on older branches only, and
nobody building the new one reads it (`CONTRIBUTING.md` § The old code).
